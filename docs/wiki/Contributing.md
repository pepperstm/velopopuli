# Contributing

Help is very welcome — testing with your trainer, fixing bugs, map rendering, new features, translations, packaging.

1. Read **[CONTRIBUTING.md](https://github.com/pepperstm/velopopuli/blob/main/CONTRIBUTING.md)** — how work is proposed, written, tested, reviewed and merged — and **[HANDOFF.md](https://github.com/pepperstm/velopopuli/blob/main/HANDOFF.md)** in the repository: what works and what doesn't yet, how the code is laid out, how to build, test and release, the next priorities, and the decisions behind things.
2. See [[Building from source]] and [[Architecture]].
3. The most valuable thing right now is **real hardware**: ride with your trainer and send a [[diagnostics report|Reporting problems]], working or not, with the model and how it was connected.

Open an issue before starting anything large, so effort isn't duplicated.
