# Building from source

Building, testing and the automated checks are described in the repository's developer pages: **[Building and testing](https://github.com/pepperstm/velopopuli/blob/main/docs/developers/building-and-testing.md)**.

In short, you need [Rust](https://rustup.rs) (stable) and [Node.js](https://nodejs.org) 20 or later, plus a few system libraries on Linux, then:

```bash
npm install
npm run dev      # the app, reloading as you edit
npm run check    # everything CI checks
```

The rest of the developer pages, one chapter for each part of the app, start at **[VeloPopuli for developers](https://github.com/pepperstm/velopopuli/blob/main/docs/developers/README.md)**.
