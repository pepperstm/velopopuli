# Keyboard shortcuts

> **New in 0.4.0.** The **?** panel and the Settings link are in the [0.4.0 release candidates](https://github.com/pepperstm/velopopuli/releases), for testing, and not yet in a full release. The other ride keys, apart from `O` for overlay mode, also work in 0.3.10.

Every key in VeloPopuli. During a ride, press **?** (the button at the bottom of the ride screen, or the `?` key) for a list of the keys that work right now, with your own gear keys and the handlebar-controller buttons that do the same. The same list is under **Settings → Gears → Keyboard shortcuts**.

## Riding

| Key | What it does | Controller button |
|---|---|---|
| `]` `=` `Page Down` `→` | Harder virtual gear (with [[Virtual gears]] on) | Shift up |
| `[` `-` `Page Up` `←` | Easier virtual gear | Shift down |
| `↑` | ERG target up 10 W, workout intensity up 5%, or the demo rider's effort up | Increase difficulty |
| `↓` | The same, down | Decrease difficulty |
| `Space` | Pause or resume | Pause / Resume |
| `C` | Change the camera: behind, high behind, alongside, overhead | Camera view |
| `O` | [Overlay mode](Riding#overlay-mode-ride-while-watching-something) on or off | |
| | Skip to the next workout step (the **Skip step** button) | Skip interval |
| `?` | Show or hide the list of keys | |

`↑` and `↓` do whatever fits the ride: in a workout they change its intensity, in ERG the target power, and with the demo rider its effort. In a free ride on the gradient they do nothing; use **Feel** on screen for how hard the hills feel.

Keys typed into a text box don't count as shortcuts.

### Your own gear keys

The gear keys are yours to change: **Settings → Gears**, choose **Virtual gears**, then **+ Add** next to *Harder gear* or *Easier gear* and press any key. Remove one with its **×**. A Bluetooth presentation clicker or media remote works too: most send the arrow or Page Up / Page Down keys, so they shift straight away. Your gear keys take priority over the other keys, so you can use any key for shifting.

### Handlebar controllers

A controller that speaks [OpenBikeControl](https://openbikecontrol.org) does the same things as the keys, with no setup beyond pairing it under **Devices**. See [Virtual gears → Controllers](Virtual-gears#controllers) for which button does what, and how a button that sends several actions is handled.

### In overlay mode

When the ride is a small panel over another app, the keys only work while the VeloPopuli panel has the keyboard: click the panel first. If you're watching a video, its window usually has the keyboard, and `Space` pauses the video, not your ride. A handlebar controller doesn't need the keyboard, so it keeps working whichever window is in front. `O`, or **⤢** on the panel, goes back to the full window.

## Planning a route

On **Explore**, while planning a route:

| Key | What it does |
|---|---|
| `⌘Z` (macOS) / `Ctrl+Z` | Undo |
| `⇧⌘Z` (macOS) / `Ctrl+Shift+Z` | Redo |
| `Enter` | Search for a place, in the search box |
| `?` | Show the planner's keys |

## Anywhere

| Key | What it does |
|---|---|
| `Esc` | Close a window such as the keyboard shortcuts or a ride importer |
